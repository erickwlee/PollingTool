# PollingTool
Tool set for polling in Q&amp;A games

This is a set of Polling Tools.
The use of the tool is to convert a smartphone to a simple tool for polling.  A smartphone loading this html tool can have its screen showing 4 different colors upon 4 choices A,B,C,D against a certain question asked. Answer A,B,C,D is using a full screen of Red, Yellow, Purple and Blue to represent. When doing the voting, someone holds his smartphone showing to the one who is asking the question, with the corresponding answer color showing up on the smartphone.
There are 2 versions of tool, the simple version is a simple tool just to show the answer choice with the choice letter and color.  The full version tracks all choice through the whole series of questions and shows a summary of the choices made with the wrap up timestamp.
